Cấu hình Google Drive Sync

Lưu trữ bảo mật trực tiếp trên tài khoản Google của bạn

Ứng dụng lưu trữ file đồng bộ focusdaily_backup.json trực tiếp trong Google Drive cá nhân của bạn, không qua bất kỳ máy chủ trung gian nào.

💡 3 bước lấy Client ID miễn phí từ Google Cloud:

1. Vào Google Cloud Console > Tạo Project mới.

2. Bật API Google Drive API trong mục Enabled APIs & services.

3. Tạo OAuth Client ID (loại Web Application). Thêm URL Vercel/localhost của bạn vào Authorized JavaScript origins.
